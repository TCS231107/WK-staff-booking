Drop the real weKnow logo here to replace the built-in one.

  public/brand/logo.svg    (preferred — crisp at any size)
  or
  public/brand/logo.png    (used only if logo.svg is missing)

The app picks it up automatically on the next page load — no code change,
no server restart needed. It appears in the top bar and on the sign-in screen.

Tip: a wide/horizontal version of the mark works best. Transparent background.
